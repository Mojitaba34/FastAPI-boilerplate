A simple and scalable FastAPI boilerplate to quickly start new projects with best practices, clean architecture, and essential configurations for fast development.

## Features
- FastAPI setup with basic configurations
- Scalable project folder structure
- Pre-configured settings for CORS, logging, and environment variables
- Dockerfile for containerized deployment
