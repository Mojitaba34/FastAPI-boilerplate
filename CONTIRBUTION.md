# Contributing to FastAPI boilerplate

We appreciate your interest in contributing to this project! To ensure smooth collaboration, please follow these
guidelines.

### 1. Fork the Repository

First, fork the repository to your own GitHub account by clicking the **Fork** button in the top right corner of the
repository page.

### 2. Clone Your Fork

Clone your forked repository to your local machine:

```bash
git clone https://github.com/Mojitaba34/FastAPI-boilerplate.git
```

### 3. Pull request

Please consider every PR should be on develop branch not on main.
